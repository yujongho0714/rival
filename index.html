1찾을 아이

아이 얼굴이 잘 보이는 영상이나 사진을 올리고, 그 아이 얼굴만 골라주세요. 여러 장일수록 더 잘 찾아요.

주황 테두리 얼굴로 바로 찾고 있어요. 다른 아이 얼굴이 섞여 있으면 눌러서 빼주세요.
👉 이제 찾을 사진·영상을 한 번만 골라주세요. 파일 창에서 DCIM → Camera 폴더(또는 ☰ → 동영상) → 하나 길게 누르기 → ⋮ → 모두 선택.
한 번 분석해 두면, 다음부터는 아이 영상만 올려도 바로 자동으로 찾아요.

2찾을 사진·영상 고르기

폰 갤러리나 구글 드라이브에서 여러 개를 한꺼번에 고르세요. PC는 폴더째 고를 수 있어요.

📱 한꺼번에 고르는 법: [📂 파일 창에서 한꺼번에 고르기] → (앱 고르는 창이 뜨면 파일 또는 내 파일) → 왼쪽 위 ☰ 에서 동영상·이미지 또는 DCIM → Camera 폴더 (드라이브는 ☰ → Drive) → 아무 파일이나 길게 눌러 선택 → 오른쪽 위 ⋮ → 모두 선택 → [선택]
사진·영상이 아닌 파일이 섞여도 알아서 빼요.
영상 살펴보는 간격
🔒 사진·영상은 이 기기 안에서만 분석되고 어디에도 올라가지 않아요. 한 번 분석한 파일은 기기에 기억해 두어서, 다른 아이를 찾을 때는 다시 분석하지 않고 바로 찾아요.
